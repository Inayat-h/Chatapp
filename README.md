Chat Application

📌 Project Overview

This is a Chat Application that allows users to communicate with each other in real time. Users can register, log in, and send messages instantly. The application is designed with a simple UI and easy-to-use features.

🚀 Features

User Registration and Login

One-to-One Chat

Real-time Messaging

User-friendly Interface

Secure Authentication


🛠️ Technologies Used

Frontend: HTML, CSS, JavaScript, React

Backend: Node.js 

Database: MongoDB

Real-time Communication: Socket.io / WebSocket

⚙️ Installation Steps

1. Clone the repository:

git clone https://github.com/Inayat-h/Chatapp.git


2. Go to the project directory:

cd chatapp


3. Install dependencies (if any):

npm install


4. Start the server:

npm start


5. Open the application in browser:

http://localhost:4002



🧑‍💻 Usage

Register a new user account

Login with valid credentials

Start chatting with other users


🔒 Security

Passwords are encrypted

User authentication is required to access chat
